## A little about me

I'm **Mark Reboroso Medina**, a **Full Stack Solo Web App Developer**. I build web applications that turn ideas into practical, usable experiences.

My current work includes **Pawhaus**: a dog hotel website with a booking flow and a staff workspace. I enjoy connecting thoughtful interfaces with the systems that make them work.

- **Building:** web experiences, booking flows, and everyday tools.
- **Working with:** JavaScript, TypeScript, Node.js, and PostgreSQL.
- **Improving:** the details between a first idea and a working product.
